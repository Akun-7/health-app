# HealthTrack — Политика конфиденциальности

*Последнее обновление: 2026-07-29*

Этот документ объясняет, какие данные собираются, как хранятся и используются при использовании мобильного приложения HealthTrack (далее — «Приложение»). Устанавливая/используя Приложение, вы подтверждаете, что ознакомились с этой политикой.

## 1. Какие данные собираются

- **Данные аккаунта:** email-адрес и хеш пароля (сам пароль нигде не хранится в открытом виде).
- **Показатели здоровья:** давление, пульс, SpO2, введённые вручную или через Bluetooth.
- **Данные профиля:** возраст, пол, вес и другие данные, которые вы вводите сами.
- **Напоминания:** напоминания о приёме лекарств/приёмах и история их выполнения (принято/пропущено).
- **Сообщения чата:** если вы общаетесь с пользователем с ролью «врач», переписка сохраняется на сервере.
- **Экстренные контакты:** имя/номер телефона, введённые для функции SOS — эти данные хранятся **только на устройстве** и не отправляются на сервер.
- **Язык и настройки:** язык интерфейса, тема (светлая/тёмная) и другие настройки.

Приложение не показывает рекламу и не использует инструменты аналитики/отслеживания действий пользователя.

## 2. Где и как хранятся данные

- Показатели здоровья, профиль и напоминания хранятся на устройстве **в зашифрованном виде (AES)** — ключ хранится в защищённом хранилище ОС (Android Keystore/iOS Keychain).
- Те же данные дополнительно копируются на наш облачный сервер (Render.com) — на случай потери/поломки устройства.
- ⚠️ **Важное ограничение:** сервер сейчас работает на бесплатном тарифе без постоянного диска — при перезапуске сервера копия данных на сервере может быть утеряна (копия на устройстве сохраняется). Это временное техническое ограничение, которое будет улучшено в будущем.
- Код восстановления пароля отправляется по email через стороннего провайдера **Resend** (resend.com) — только для этого ваш email передаётся данному сервису.

## 3. Третьи стороны

Приложение использует следующие сторонние сервисы:
- **Render.com** — серверная инфраструктура (хостинг)
- **Resend** — отправка email для восстановления пароля

Мы не продаём и не передаём ваши данные третьим лицам в рекламных или иных целях.

## 4. Ваши права

- Вы можете удалить данные профиля/измерений с устройства через раздел «Настройки» → «Очистить все данные».
- Чтобы полностью удалить аккаунт (включая данные на сервере), свяжитесь с нами по контакту ниже.
- Вы имеете право запросить копию сохранённых о вас данных.

## 5. Дети

Приложение не предназначено для детей и не собирает данные о детях намеренно.

## 6. Безопасность

Медицинские данные шифруются с помощью AES, но ни одна система не может быть на 100% защищённой. Держите устройство защищённым PIN-кодом/биометрией.
